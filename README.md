C# Gym-Management-App
a gym management application using C# with Windows Forms and ADO.NET provides a user-friendly interface for managing member information, class schedules and training programs. It ensures data security and ease of use for staff, featuring user authentication and registration functionalities to streamline operations

FEATURES:
- CRUD operations for member data
- Class scheduling management
- Training program management
- User authentication and registration
- Data security measures

TECHNOLOGIES USED:
- C#
- Windows Formd
- ADO.NET
- SQL Server
